# Research revision and document change map

Revision: v2, 3 October 2026. This map accounts for every previous Markdown file and the four additions. The project name, track, deadlines and integrity principles stay; the active product and implementation work change to the latest recovered research direction.

## Why the scope changed

The prior pack scoped BenchProof to ML experiment auditing. The recovered coding-agent research instead proposed an Agentic Engineering Assurance Runtime, with executable constraints, engineering-state relationships, stale-context handling, trajectory control, adversarial checks and evidence. Primary documentation confirms substantial existing coding/memory/execution capabilities across the eight reviewed products; we cannot treat those ordinary features as unique.

This revision adopts the connected assurance workflow and limits it to a feasible Python service. The research is desk research plus product hypotheses; it supplies no actual competitor scores. The former plan had no completed code or measurement to carry forward.
